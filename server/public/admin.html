Phone Setup

Steps to turn a new iPhone or Android phone into a scanner. Works over this WiFi network only — the phone won't be able to reach the server off this LAN.

iPhone

1. Join this WiFi network
Same network as this computer. Required for every step below and for scanning afterward.
2. Trust the server's certificate
Open this link in Safari, then go to Settings > General > VPN & Device Management and install the downloaded profile, then Settings > General > About > Certificate Trust Settings and turn on full trust for it. Or just scan the QR code with the iPhone's camera.
